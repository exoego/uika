# Build tool logos

These files back the logo grid in the README's Usage section. Each is a copy
of the file its project publishes. They are trademarks of their owners and are
used here only to point at that project's integration page. The `-dark`
variants are the project's own dark-background versions; a tool without one
uses a single file for both themes.
